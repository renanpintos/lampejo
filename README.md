## Running 
Access the project directory (e.g., `lampejo/`) and run:

### Frontend Project

Run:
```bash
cd frontend
```

```bash
npm install
```

```bash
npm run dev
```


### Backend Project
Run: 
```bash
cd backend
```

```bash
npm install
```

```bash
npm start
```


## Access the page:
Frontend: http://localhost:5173/

Backend: http://localhost:3000
